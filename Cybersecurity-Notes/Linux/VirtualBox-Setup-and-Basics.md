## Essential Linux Commands
Here are some of the fundamental commands I learned during my TryHackMe Linux Fundamentals path:

- `pwd`: Print Working Directory. Shows exactly where you are in the file system.
- `ls`: List. Shows the files and directories in the current folder.
- `cd`: Change Directory. Used to navigate through the file system.
- `cat`: Concatenate. Used to output the contents of a file to the screen.
- `echo`: Used to print text to the terminal or write to files.
- `find`: Used to search for files in a directory hierarchy.
- `grep`: Used to search for specific text within files.
